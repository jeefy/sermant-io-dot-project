# Security Policy

## Reporting Security Issues

The Sermant maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/sermant-io/Sermant/security/advisories/new) form.

For more details, see the [Sermant security policy](https://github.com/sermant-io/Sermant/blob/develop/SECURITY.md).
